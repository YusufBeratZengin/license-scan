# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

We take the security of `license-scan` seriously. If you discover a security vulnerability or potential issue, please follow these steps:

1. **Do not disclose the issue publicly** in issue trackers, forums, or social media.
2. Report the vulnerability via GitHub Security Advisories:
   `https://github.com/YusufBeratZengin/license-scan/security/advisories`
   Alternatively, contact the maintainer directly at:
   `118852217+YusufBeratZengin@users.noreply.github.com`.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps or proof-of-concept to reproduce the behavior.
   - Affected ecosystem or file parser (Node or Python).
   - Any suggested mitigations.

## Response SLA

- Initial response acknowledging receipt: within 48 hours.
- Assessment and patch timeline: within 7 business days for high-severity issues.
- Public disclosure: coordinated release after the patch is published.
